# BMI Calculator 🏃‍♀️

SEN210 - User Interface Programming

BMI Calculator is a simple desktop application built with Python and PyQt6.

## Project Idea

The application allows the user to enter their weight and height, then calculates their BMI and shows their health status.

## Features

- Enter weight in kg
- Enter height in meters
- Calculate BMI instantly
- Shows health status (Underweight, Normal, Overweight, Obese)

## App Structure

- `bmi.py` → main application file (UI + logic)
